## 1. 认识 HDevelop（20 分钟）

打开 HDevelop（`D:\Program Files\MVTec\HALCON-23.11-Progress\bin\x64-win64\hdevelop.exe`），认识 4 个窗口：

| 窗口 | 作用 |
|---|---|
| 程序窗口 Program | 写代码。左侧的绿色箭头表示"下一行将要执行的位置" |
| 图形窗口 Graphics | 显示图像、区域、轮廓。鼠标滚轮缩放 |
| 变量窗口 Variables | 上半部分是**图形变量**（图像、区域、轮廓，显示缩略图），下半部分是**控制变量**（数字、字符串）。双击变量就能显示或查看它 |
| 算子窗口 Operator | 输入算子名，会列出参数并给出说明，按"确定"插入到程序里 |

常用快捷键：

| 键 | 作用 |
|---|---|
| F5 | 运行 |
| F6 | 单步执行（遇到过程不进入） |
| F7 | 单步进入过程（以后写本地过程时用） |
| F2 | 复位，回到第一行，清空变量 |

在程序窗口里选中任一算子按 F1，会打开该算子的帮助文档。**遇到不认识的算子先按 F1**，帮助里有参数说明和例程。

## 2. HALCON 的四种数据（30 分钟，最重要）

| 类型 | 是什么 | 例子 | 对应 OpenCV 里的 |
|---|---|---|---|
| 图像 Image | 像素灰度矩阵，**带一个定义域（domain）** | `Gray` | `np.ndarray` 灰度图 |
| 区域 Region | 一组像素的集合，**没有灰度值**，只记录"哪些像素属于它" | 阈值结果、圆、缺陷 | 二值掩膜 `mask` |
| 轮廓 XLD | 亚像素精度的点序列 | 拟合出的圆轮廓 | `contour` |
| 控制变量 | 数字、字符串、句柄，都是**元组（tuple）** | `Area := [545, 778]` | Python 的 list |

**算子的参数顺序永远是这样**（冒号分成 4 组）：

```
算子名 (输入图形 : 输出图形 : 输入控制参数 : 输出控制参数)
threshold (Gray, DarkRegion, 0, 80)
```
`Gray` 是输入图像，`DarkRegion` 是输出区域，`0, 80` 是输入控制参数。

**为什么 HALCON 好用**：OpenCV 版要自己画一张张掩膜，再做 `bitwise_and`；HALCON 里区域就是对象，可以直接做集合运算：

| 要做的事 | OpenCV 版写法 | HALCON 写法 |
|---|---|---|
| 两个掩膜求交 | `cv2.bitwise_and(a, b)` | `intersection (A, B, C)` |
| 求并 / 求差 | `bitwise_or` / `subtract` | `union2` / `difference` |
| 连通域 | `connectedComponentsWithStats` | `connection` |
| 面积、重心 | `countNonZero` / `moments` | `area_center` |
| 填充内部孔洞 | `findContours` + `drawContours(-1)` | `fill_up` |
| 椭圆核开/闭运算 | `morphologyEx` | `opening_circle` / `closing_circle` |
| 均值滤波 | `cv2.blur` | `mean_image` |
| 局部暗差分阈值 | `subtract` + `threshold` | `dyn_threshold`（一个算子搞定） |
| 最小外接旋转矩形 | `minAreaRect` | `smallest_rectangle2` |
| 最小外接圆 | `minEnclosingCircle` | `smallest_circle` |

**元组的小规则**：下标从 0 开始；`|T|` 是长度；`[A, B]` 是拼接；字符串加数字会自动拼成字符串，例如 `'R=' + Radius`。
